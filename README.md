## 공개 테스트 2 변경점

- 골드 획득 알림을 `88 골드 획득!` 형식으로 한글화했습니다.
- 아이템 획득 알림을 `불의 항아리 획득!`처럼 표시하도록 수정했습니다.
- 아이템 목록의 별도 출력 함수에 빠졌던 한글 타일 주소 변환을 추가했습니다.
- 획득 알림 글꼴을 일반 영문자, 보스 대사, 마법 HUD, 몬스터 그래픽 영역과 분리했습니다.

기존 메뉴 가드는 유지됩니다. 메뉴 한글 글꼴과 그래픽 영역이 겹치는 오브젝트는 **메뉴가 열린 동안만 숨기고**, 닫으면 복구해 다시 표시합니다. 모든 몬스터를 메뉴 중에도 계속 표시하는 방식은 아니며, 기존 메뉴 종료 복구 지연도 남아 있습니다.

이전 강제 저장에는 옛 그래픽 메모리가 포함될 수 있습니다. 열린 메뉴는 닫고 다시 열어야 하며, 이전 획득 알림도 새 획득 이벤트가 발생하기 전까지 바뀌지 않을 수 있습니다. SRAM 저장 형식과 보상량은 이번 수정에서 변경하지 않았습니다.

## 이번 버전의 검증과 한계

- PicoDrive에서 아이템 59종과 금액 10종을 두 상태에서 호출한 138건 통과.
- 실제 메뉴 입력으로 아이템 목록 11종의 타일 주소와 글꼴 픽셀 확인.
- 획득 알림 표시, 시간 만료, 알림 중 메뉴 개폐 확인.
- 보스 대사 6경로와 마법 HUD 6종의 36조합에서 글꼴 영역 보존 확인.
- 기존 메뉴/몬스터/힘 마법 회귀검사 재실행: 검사 구간에서 화면에 보이는 충돌과 이전 기준본 대비 측정한 게임 상태 차이 없음.
- 원본에 IPS를 적용한 결과가 시험한 롬과 바이트 단위로 일치.

제보 세이브 복사본과 그래픽 배치를 옮긴 통제용 상태를 포함한 제한적 검사입니다. 아이템을 전체 맵에서 모두 직접 습득한 완주 검사가 아니며, 보스 경로 검사도 실제 보스전 전체 검증과 다릅니다.

**전체 게임 완주, 실제 제보 보스방, Fusion, 다른 RetroArch 코어, 메가드라이브 실기/EverDrive는 이번 수정본으로 미검증입니다.** 모든 대사와 진행 이벤트의 무오류를 보장하지 않습니다.
